## 五、模型 / 训练工程（坑类）
- **🔴 推理预处理必须与训练一致**：Detector 必须 **letterbox**（等比缩放+114 灰边填充+坐标回映射），**不能直接 cv2.resize 拉伸**（同模型 10/35 → 20/35）。`[来源 2026-08-21]`
- **RT-DETR onnx 输出 `[1,300,6]` = 归一化 xywh+score+cls**；YOLO 输出 `[1,6,N]` **必须 `transpose(1,0)`** 解析。`[来源 2026-08-21]`
- **🔴 RT-DETR 解析**：`score=p[4]; cls_id=int(p[5])`；用 `argmax(p[4:])` 会把 `[score,cls]` 当双类分数 ⇒ **fire 分数恒虚高 1.0**（`confFire` 过滤失效的深层根因）。`[来源 2026-08-26]`
- **RT-DETR onnx 导出必须 `opset>=16`**（opset=12 直接 AssertionError）。`[来源 2026-08-29]`
- **🔴 RT-DETR 续训必须 `amp=False`**：AMP fp16 在 3 类大 loss 下 epoch8+ 变 nan 发散（多次验证）。`[来源 2026-08-30]`
- **🔴 禁用 bulk-class 批量改类**：把模型原检出框批量改类会污染训练集（曾教会"UI=smoke"，30 张无烟图吐 251 smoke 框）；训练 smoke **必须逐张精确画烟框**。`[来源 2026-08-26]`
- **域差距 = v4 失败根因**：smoke 训练框 99.8% 来自 D-Fire/CCTV 域 ⇒ 学到"类烟纹理"却无法定位；**域外数据占比须封顶 ≤30~40%**。`[来源 2026-08-27]`
- **生产 m6_rtdetr（v3）= "类错目标对"**：对 1km 细烟召回 97.6% 但误报 94%（全报 fire 类）。`[来源 2026-08-28]`
- **受控合成烟 `v5_syn`**：alpha = 半透明白雾气 `bg*(1-α)+255*α`（**不是贴素材原色**）+ 灰度亮度 + Sobel + 17×17 GaussianBlur 羽化；远距小目标 25~90px。`[来源 2026-08-28]`
- **内存红线**：7024 图 @960 `cache=ram`≈78GB 安全；@1280 ≈139GB **超内存**。`[来源 2026-08-29]`
- ultralytics 权重/D-Fire 数据集走 **hf-mirror.com**（GitHub 慢）；D-Fire（CC0，0=smoke/1=fire）。

## 七、前端验收 / 沙箱补充
- **React 受控 input**：直接 `inp.value=` / `dispatchEvent` **不触发 onChange** ⇒ 用原生 setter `Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(inp,...)` + 触发 input 事件。`[来源 2026-08-31]`
- **`<button>` 是 React 事件委托**：原生 `el.click()` 不触发 onClick ⇒ 用 `page.mouse.click(x,y)` 真实坐标。`[来源 2026-08-30]`
- **`authFetch` 返回原生 Response**，组件必须 `.json()`（曾把 Response 存 state → "暂无数据"永远显示）。`[来源 2026-08-26]`
- **`localStorage` token 键 = `jsc:token`**（带冒号，非 `jsc_token`）。管理后台入口：主页先点顶栏 **BUTTON「管理后台」** 才出侧边栏；菜单文本「AI环境防控」。`[来源 2026-08-31]`
- headless 匹配中文菜单：`includes` 前须 `filter(offsetParent && r.x>=150)` 区分侧栏与主区（侧栏文本含"检测结果"会误命中）。`page.evaluate` **不接受函数参数**（predicate 必须字符串化）。`[来源 2026-08-30]`
- 天地图瓦片有 **HTTP 429 频率限流**（高并发/多进程会打爆，恢复>60s 甚至小时级）⇒ 下载器必须**单实例**。`[来源 2026-08-05]`
