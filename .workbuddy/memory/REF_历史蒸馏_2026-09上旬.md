## 七、检测引擎细节
- **🔴 detector.py yolo 解码分支**：ultralytics 标准导出 box = **输入画布绝对像素** + cls 已 sigmoid（`(1,5,33600)`=nc1 三检测层）；旧分支按 2 类 hack（`p[5]` 当 cls_id）对 nc=1 **越界+坐标错乘 size**；正解 = `argmax(cls_scores)` + 直接减 letterbox 偏移。备份 `detector.py.bak_yolov5_0902`。`[来源 2026-09-02]`
