## 一、标注铁律（用户定调 · 最高优先级）
- 工具内置防污染；**宁多标不进脏数据**；拿不准 → 「不确定/暂缓」；可疑样本**隔离分区、默认不入集**。
- **新标注页照抄 7 道闸**：同景警示｜导出门禁（新增负 > 新增正×2 阻断）｜昼夜配比（夜负 ≤ 昼负×1/2）｜
  易误检区未画即提醒｜全黑帧预检锁定｜已入集锁定只读｜`SIM_*` / 机场直连黑名单。
- **正负增量同批匹配**（教训：+7 正塞 26 难负 → 召回 95%→75%）。
- **图上叠框必须与图像同宽高比（禁 `object-fit:cover`）**：`scale=min(W/vw,H/vh)` + 居中偏移 + clamp；
  尺寸读 `<video>.videoWidth`。
- **「等效目标像素尺寸」比原始分辨率更关键**；尺度偏移的批次要配平（`/video/xunlian/asset_check.py`）。

## 二、标注协议 v1.2（2026-09-29 上线）
- **五档**：`确定烟 / 明火+烟 / 明火 / 疑似轻烟 / 非烟`（v1.1 三级装不下"夜间火光"）。
- **门禁只走粗口径**：`焚烧(确定烟+明火+烟+明火) / 疑似 / 非焚烧` **≥0.80 硬门槛**；
  **五档细口径仅参考、不卡门禁**（都认"在烧"，只是火烟成分不同；硬按五档卡会淹没真分歧）。
  尺度档 ≥0.80 亦为硬门槛；IoU ≥0.50 仅正式批次。

  **localStorage 键 `anchor_wb_v12_*`**（口径变必升版，旧进度不迁移）。
- **协议 / 工作台 / 入口页三者版本号必须一致**（审计脚本交叉比对）。导出 `anchor_annot_v12_{A,B,both}.json`。

## 三、训练集污染（2026-09-29 实证）
- **判据 = 分辨率 × 宽高比**：无人机视频帧只有 **960×720 / 1280×720 / 1440×1080**（4:3、16:9）；
  **桌面截图 = 2968×1732 / 2560×1329 / 2942×1732**（宽高比 1.714 / 1.926 / 1.699，**非 16:9**）。
  工具 `tmp/audit_dataset_ui.py`（PIL 只读头，秒级）。
- 实测污染量：`v5_train_v5` 930 张 → **108 张桌面截图（11.6%）**（`misc/` 107 + `wechat_fix/` 1）；
  `v6_train` 3058 张 → **321 张（10.5%）**（`images/train` 290 + `val` 31 —— **v6 更新影响更直接**）。
- **生产输入"零 UI"实证**：实飞抽帧 `evidence/review/sikong_*/random_*.jpg` 是**纯相机画面**
  （无参数栏/遥测/地图/摇杆）⇒ UI 截图是**真域污染**，可能是"白天框级定位差"的成因之一。
- **🔴 铁律：「数据集目录名」≠「画面里有没有 UI」——必须看图。**
  （9/28 据目录名判"v5_train_v5 整批是司空截图"，实测 **v5 那 19 张全干净**；真正带 UI 的是
  `v6_train` 3 张 + 标注平台截图 2 张 + 撕裂坏帧 2 张。详见 `docs/锚点集缺陷审计_20260929.html`）

## 四、抽帧侧的同类判据（`record_frames.py --audit`）
体检**只抓真污染**：`宽度 ≥ 2000`（桌面截图特征，三个已知污染尺寸全命中）或 `宽高比 > 2.1 / < 0.8`。
⚠️ **别用「必须等于 4:3 或 16:9」当判据** —— 会把 **704×576(D1)**、800×600 等**合法摄像头尺寸误杀**（已踩）。

## 五、VLM 预筛的定位（2026-10-01 起）
- ❌ **不做**：VLM 直接出框 / 用文字提示驱动 YOLO（已论证：模型本质错位 + 小目标定位精度不足）。
- ✅ **只做**：离线**预筛**（挑候选帧交人工整框）+ **难负挖掘**（模型报了但 VLM 判无烟 → hard negative）。
- 流水线：录制/抽帧 → **VLM 预筛** → 人工复核准入 → 协议 v1.2 五档整框 → 入训练集。
- 工具：`infra/vlm/prescreen.py`（run/review/summary/one）；复核台**只做三态确认、不画框**。
- 性能（热态，qwen2.5vl:7b）：裸回答 0.10 s/帧｜schema 仅 has_smoke 0.26 s/帧｜schema+reason 0.37 s/帧。
  ⚠️ **冷启动另计 ~30 s**（模型被 KEEP_ALIVE 卸载后首次调用）⇒ **测吞吐必须先预热 否则会误判**。
