① OSD 同步地图：已实现——驾驶舱电子地图已实时显示无人机位置（MapView 15s 轮询 /api/sikong/devices，无人机飞行实时位置标记）。可增强：提高刷新频率、加飞行轨迹、加朝向箭头。

② 画中画小地图：可实现，约 1.5~2 天——视频放大后，左下角加一个 Leaflet 小地图实例，实时显示无人机位置 + 朝向箭头，让用户"一边看画面一边知道无人机在哪、朝哪飞"。

#需求

三、现状盘点

对象现状
OSD 同步地图已实现 MapView 司空机场标记 + 无人机飞行实时位置标记（drone.latitude/longitude，OSD deviceType=1 帧回填），15s 轮询 /api/sikong/devices

四、技术方案

4.1 整体链路

司空 OSD → Redis osd_dock_drone（经纬度/朝向/高度） → 后端 /api/drone-events/osd?deviceSn=（读 Redis，实时返回） → 前端 MiniDroneMap 轮询（2~3s） → Leaflet 小地图：位置标记 + 朝向箭头 + 地图跟随 → 放大层左下角 absolute 定位显示

4.2 三个组成部分

组成内容
① 后端 OSD 接口GET /api/drone-events/osd?deviceSn=，从 Redis osd_dock_drone:<deviceSn> 读实时遥测，返回经纬度/高度/朝向(attitudeHead/gimbalYaw)/速度/电量/目标点 measureTarget
② 前端 MiniDroneMap 组件Leaflet 小地图实例（~220×160px），天地图瓦片；轮询 OSD 接口（2~3s），渲染无人机位置标记 + 朝向箭头（按 attitudeHead 旋转），地图中心跟随无人机位置
③ 集成到放大层DronePopupWindow 的 zoomed 放大层画面容器左下角，absolute 定位放 MiniDroneMap

4.3 小地图显示内容

元素说明
无人机位置标记当前经纬度，醒目图标（脉动圆点）
朝向箭头按 attitudeHead（机头朝向）旋转的箭头，指示飞行方向
机场位置（可选）所属机场 dock 位置（参照点）
高度/速度标签（可选）小地图角落显示 height/horizontalSpeed
地图跟随地图中心实时跟随无人机位置（setView），保持无人机在视野中心

六、关键设计决策点

决策点选项建议
小地图引擎A. Leaflet（与主地图一致）B. 静态瓦片+标记 C. 新地图库A Leaflet——与主地图一致，交互/瓦片复用，开发量小
OSD 数据接口A. 新增 /api/drone-events/osd B. 复用 /api/sikong/devicesA 新增——直接读 Redis osd_dock_drone，实时性强（devices 是 15s 聚合，不够实时）
朝向显示A. attitudeHead（机头）B. gimbalYaw（云台）A attitudeHead——机头朝向更直观反映飞行方向
刷新频率小地图 OSD 轮询2~3s——与 OSD 推送频率匹配，兼顾实时与性能

七、风险与注意点

风险说明 + 对策
小地图性能放大层已有一个大地图（Leaflet 实例），再加小地图是第二个实例——注意内存/性能；小地图用轻量配置（少交互、固定缩放级别）
瓦片加载小地图在放大层（全屏覆盖），瓦片需在线加载天地图；离线场景需用本地瓦片
OSD 数据延迟OSD 推送有延迟（几秒），小地图位置非严格实时——可接受（监控场景）
地图跟随抖动无人机高速移动时地图频繁 setView 可能抖动——加平滑过渡/阈值（位置变化>X 才跟随）

八、结论

① OSD 同步地图已实现（无人机实时位置已在主地图显示），可选增强（刷新提速+轨迹+朝向）；
② 画中画小地图可实现，约 1.6 天（后端 OSD 接口 0.3 + MiniDroneMap 组件 0.8 + 集成 0.2 + 联调 0.3）；
③ 技术方案清晰：Leaflet 小地图 + Redis OSD 实时数据 + 朝向箭头 + 地图跟随；
④ 核心价值：用户放大视频时，左下角小地图实时显示"无人机在哪、朝哪飞"，解决"看画面不知道位置"的痛点。
