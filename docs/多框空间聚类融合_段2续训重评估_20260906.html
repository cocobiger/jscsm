现象：真烟图里 smoke 框常出现 5~6 个重叠框（同一烟区被模型重复检测）。

两个待解决问题：

问题内容
① 多框如何利用用户提议「5框+4个conf>0.5 → 判真烟」，上轮评估为「方向对但执行错」（数框数无法区分单烟区冗余 vs 多烟团 vs 误报聚集）
② 段2 续训v5 stage2 对远烟/弱烟漏检、对干扰项误报，需用人工治理后的干净数据续训

二、多框「空间聚类 + 多信号融合」思路细化

2.1 核心思想：先聚类归并，再逐簇判定

多框的正确语义不是「框数越多越真」，而是——先按空间位置把重叠框归并为「簇」：簇数 M = 画面里独立的疑似目标数；簇内框数 n = 模型对单个目标的响应强度（冗余度）。

这样「单烟区 5 个重叠框」= 1 个簇（M=1）+ 簇内 5 框（n=5）；「画面里 3 处独立烟」= 3 个簇（M=3）；「固定背景误报聚集」= 1 个簇（M=1）但 conf 分布异常 / 时序不连续——三者终于可分。

2.2 空间聚类算法（轻量，逐帧 CPU 可忽略）

步骤实现
输入一帧 N 个 smoke 框 [x1,y1,x2,y2,conf]
距离度量两框 IoU（重叠度），或中心距 / 框对角线均值
归并规则贪心并查集：IoU > 0.3 的两框合并入同簇（等价轻量 DBSCAN）
输出M 个簇，每簇含 n 个框 + 合并后 bbox + 中心点
复杂度O(N²)，N≤20 时 <0.1ms，CPU 零负担

2.3 簇级特征（每簇计算 4 个信号）

信号含义怎么用
① conf_max / conf_mean簇内最强框 / 平均置信度核心信号（单目标可信度）
② conf_std（离散度）簇内置信度一致性误报特征：真烟框 conf 较一致；误报聚集 conf 高低跳变 → std 大
③ 框数 n（冗余度）模型对单目标响应强度弱正信号：n≥2 说明多尺度锚点都命中（真实目标特征）；n=1 可能是单点误检
④ 时序稳定度Confirmer 连续帧命中（现有）强信号（连续 3 帧才告警）
⑤ 定位精度OSD 定位来源 engine/osd/dock（现有）辅助信号（osd 精确定位加分）

2.4 簇级判定得分（融合公式，可落地）

S = w₁·conf_max + w₂·(conf_max−conf_std) + w₃·g(n) + w₄·时序命中 + w₅·定位
建议权重：w₁=0.45, w₂=0.15, w₃=0.15, w₄=0.20, w₅=0.05
g(n)= min(1, n/4)（框数饱和映射，4 框封顶，避免「堆框数」）
告警门：S ≥ 0.55 且 conf_max ≥ 0.30（远烟弱烟不被 0.5 硬门槛误伤）

关键设计：conf_std 惩罚 是「误报聚集」的杀手——真烟多框 conf 收敛（std 小），误报背景多框 conf 抖动（std 大），公式自动压低误报簇得分。这比「数框数」科学得多。

2.5 与现有链路融合点

现有模块改造
detector.predict输出框后加「空间聚类」→ 返回 M 簇（不改模型）
Confirmer从「按框 update」改为「按簇 update」，连续 3 帧同簇命中才告警
reporter告警载荷带簇特征（M/n/conf_max/std）供研判
前端可视化画布只显示每簇「合并后主框」，标注 n 框/conf

四、聚类融合 + 续训的协同关系

维度空间聚类融合（后处理）续训（模型能力）
解决什么多框冗余 → 归并；误报聚集 → conf_std 惩罚远烟漏检、干扰项误报（根本能力）
生效速度改 detector/Confirmer，1-2 天即可上线需数据治理完 + 训练，周期长
关系互补不冲突：聚类融合是「现有模型结果的后处理优化」，续训是「换更好的模型」。两者可并行，聚类融合先上线止血，续训随后替换模型。

六、风险与回滚

风险等级缓解/回滚
聚类参数（IoU 阈值）不当 → 误并/漏并P1参数可配置 + 用真实多框样本离线调参
续训数据未治净 → 再次负优化（9/2 教训）P0治理完成前不启动 B3；训练前数据校验（框数/类别分布）
续训过拟合/域偏P1双组 val（DJI + CCTV）双验收，任一组退步则停
聚类融合引入新误报P1开关化（feature-flag），可一键回退到原 Confirmer

七、结论与决策点

① 多框利用的正确做法是空间聚类归并 + 簇级多信号融合（簇数=独立目标数，簇内 conf_std 惩罚误报聚集），而非简单数框数；② 段2 续训必须等 v54 治理完成，9/2 未治理数据续训已证明负优化；③ 两者互补：聚类融合先止血（1-2 天），续训换模型（治理 + 训练周期长）。

决策点：① 是否先批 路线A（聚类融合） 立即开发上线？② 治理节奏确认（v54 1031 帧 + g1 49 帧，当前进度多少？）③ 路线B 续训在治理完成后是否由我自动触发（数据集合并 + 训练 + 验收）？
