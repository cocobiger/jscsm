一、结论摘要（3 个最有价值的启发）

① 直接用 FASDD_UAV 数据集补"DJI 远景淡烟"训练域——武汉大学开源的 2.5 万张无人机航拍火焰+烟雾数据集，专门含"远景/不同距离/不同光照"样本，这是本项目缺的真实域，可直接下载用作训练补充，最快路径。

② 借鉴"Cycle-GAN 合成逼真烟"改进 v5_syn——当前 v5_syn 是"白色块"（不真实），导致模型只认白块；用 Cycle-GAN 生成逼真烟雾，能缩小合成域与真实域的差距。

③ 引入"注意力机制 + 小目标优化 + other 类区分误报"——抑制云/雾/反光干扰（本项目误报率高的根因之一），优化远景淡烟（小目标）检测。

四、最有价值的启发（落地映射）

启发①：用 FASDD_UAV 补"DJI 远景淡烟"训练域（最快路径）

现状：本项目缺"DJI 远景淡烟"真实样本（检出率 ~6.7% 的根因）。主动制造真实烟需 4~6 天（采集+标注+训练）。

FASDD_UAV 的价值：武汉大学开源，2.5 万张无人机航拍火焰+烟雾，专门覆盖"近/远距离、昼/夜、不同传感器"，YOLO/VOC/COCO 格式齐全，可直接下载。

落地：下载 FASDD_UAV 子集 → 筛出"烟雾（远景）"样本 → 与 v5_syn 混合微调 → 预期真实烟检出率显著提升。比"主动制造真实烟"快得多（省去采集+标注），且样本量大、多样性好。

注意：FASDD_UAV 的烟雾场景与本项目"秸秆焚烧"场景可能不完全一致（多为森林/建筑火灾），需筛选匹配场景的子集，或与主动制造的真实烟混合使用。

启发②：Cycle-GAN 合成逼真烟改进 v5_syn

现状：v5_syn 是"白色块"（不真实），模型只认白块，对真实烟（颜色/纹理/扩散形态不同）失效。

借鉴：Smoke-Exp 用 Cycle-GAN 把"白块烟"转换成"逼真烟"（学习真实烟的颜色/纹理/透明度），Vehicle Smoke Synthesis 用"mask 模式+滤波"生成逼真烟雾。

落地：用 Cycle-GAN 或改进的烟雾生成算法，把 v5_syn 的"白块"换成"逼真烟雾"，缩小合成域与真实域的差距。这样合成烟也能学到真实烟特征，缓解"只认白块"的问题。

启发③：注意力机制 + 小目标优化 + other 类区分误报

现状：本项目误报率高（云/雾/反光/清晨薄雾干扰），且远景淡烟是小目标难检。

借鉴：

① 注意力机制（EDA/SimAM/自注意力）：让模型聚焦烟雾特征，抑制云/雾/反光干扰 → 降误报；

② 小目标优化（SPD-Conv / 4×下采样检测头 / 多尺度）：远景淡烟是小目标，优化小目标检测头 → 提升召回；

③ other 类区分误报（D-Fire/NEWFireSmoke 三类）：加"other"类专门标注云/雾/反光/灯光等误报源 → 模型学会区分"真烟 vs 像烟的非烟"→ 降误报。

五、落地建议（结合本项目）

#建议借鉴来源优先级
1下载 FASDD_UAV 补真实域：筛"远景烟雾"样本，与 v5_syn 混合微调FASDD（武汉大学）P0
2用 Cycle-GAN 改进 v5_syn：白块→逼真烟雾，缩小域差距Smoke-Exp / Vehicle SmokeP1
3引入注意力机制（SimAM/EDA）：抑制云/雾/反光误报MEDA-YOLO / YOLOv7-tinyP1
4加"other"类区分误报源：标注云/雾/反光/灯光，三类训练D-Fire / NEWFireSmokeP1
5小目标优化（SPD-Conv/多尺度检测头）：提升远景淡烟召回YOLOv7-tiny 输电线路P2
6主动制造真实烟（保留）：烧秸秆+无人机拍，补"秸秆焚烧"特定场景本项目原评估P2

六、结论

① 最有价值的启发是"FASDD_UAV 数据集"——直接补"DJI 远景淡烟"真实域，比主动制造真实烟快得多（省去采集+标注），且样本量大（2.5 万张）；
② 合成烟真实性是次因：v5_syn 白块不真实，可用 Cycle-GAN 改进；
③ 误报率的根因是"缺 other 类 + 缺注意力"：云/雾/反光干扰可通过"other 类区分 + 注意力机制"抑制；
④ 推荐组合：FASDD_UAV 补真实域（P0）+ Cycle-GAN 改进合成烟（P1）+ 注意力/other 类降误报（P1）+ 主动制造秸秆烟补特定场景（P2）。

本报告基于 2026-09-08 GitHub 烟雾/火灾检测项目调研（FASDD / Smoke-Exp / MEDA-YOLO / YOLOv7-tiny / SASC-YOLOX / D-Fire / NEWFireSmokeDataset / Pyronear 等），结合本项目"模型对真实烟盲"痛点分析。核心结论：FASDD_UAV 数据集是最快补足"DJI 远景淡烟"真实域的路径。
