## 6. 本次新增的门禁怎么用

```bash
# 正常推送会自动跑（先密钥扫描，后类型检查）
git push origin master          # → [pre-push] 密钥扫描 … → [pre-push] 类型检查 …

# 手动只跑扫码
git ls-files -z | node scripts/secret-scan.mjs

# 有误报：在该行加 `secret-scan:ok`
# 有存量要登记：写进 scripts/secret-scan-allowlist.txt（格式 `路径:行号  # 原因`）
# 紧急跳过（**慎用**）：git push --no-verify
```

**注意**：门禁只看**工作区尖端**，不做历史扫描 —— 这也是为什么"轮换"必须人工做。
