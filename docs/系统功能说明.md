# 万州区生态环境局智能AI大数据驾驶舱系统 —— 系统功能说明

> 版本：v2.0 | 日期：2026-06-18



## 一、系统概述

万州区生态环境局智能AI大数据驾驶舱是一套集 **实时数据采集、视频监控管理、智能告警推送、可视化驾驶舱** 于一体的生态环境智慧监管平台。系统以"一张图"为核心设计理念，将大气监测、水体监控、视频巡检、告警处置等业务深度融合，实现了从数据汇聚到智能决策的全链路闭环。

### 1.1 系统架构

系统采用 **前端（React + TypeScript + Vite）+ 后端（Node.js + Express）+ 流媒体（ZLMediaKit）+ 消息队列（MQTT）** 四层架构。

| 层级 | 技术栈 | 核心职责 |
|------|--------|----------|
| 可视化驾驶舱 | React 18 + TypeScript + 高德地图 AMap 2.0 + ECharts/Recharts | 数据可视化、视频播放、地图交互 |
| 业务后端 | Node.js + Express + node:sqlite | API 服务、业务逻辑、数据持久化 |
| 流媒体层 | ZLMediaKit + FFmpeg | 视频流转码、多协议输出（RTSP/HLS/FLV/WebRTC） |
| 消息接入层 | MQTT Broker + MQTT.js | 实时告警接入、设备数据推送 |

### 1.2 核心数据流

```
传感器/设备 → MQTT Broker → 前端实时展示 + 后端事件入库
                                    ↓
                         智治推送引擎: 规则匹配 → HTTP推送 → 城运中心
摄像头 RTSP → ZLMediaKit 转码 → HLS/FLV/WebRTC → 驾驶舱播放
气体采集 → 定时调度器 → API爬取/网页爬取 → 预警判断 → 短信推送
```

## 二、驾驶舱核心功能

驾驶舱是系统的可视化主界面，采用左-中-右三栏布局，提供全域态势感知能力。

### 2.1 顶部导航栏

- **多视图切换**：全域态势 / 气环境驾驶舱 / 水环境驾驶舱
- **实时数据徽章**：监测站数量、摄像头数量、今日告警数，全自动10秒轮询刷新
- **无人机溯源入口**：一键跳转无人机溯源追踪平台

### 2.2 中间地图区（高德地图 2.0）

- **暗蓝政务主题**：专业政务驾驶舱视觉风格
- **7 种标注类型**：气站 / 监测站 / 水站 / 排污口 / 摄像头 / 无人机 / 告警点
- **智能交互**：
  - **悬停数据弹窗**：鼠标悬停标注自动拉取最新采集数据（AQI、PM2.5、PM10、SO₂、NO₂、O₃、CO）
  - **双击视频播放**：双击摄像头/无人机标注直接推流播放
  - **地图位置保护**：关闭视频后自动恢复双击前的地图位置和缩放等级
  - **交互说明面板**：右上角"?"按钮随时查看操作指南
- **叠加层切换**：气环境叠加卡（气体快检/扬尘/企业监控）/ 水环境叠加卡（流域水质/排污口）
- **图例面板**：左上角直观展示所有标注类型
- **图标可配置化**：标注图标样式通过管理端自定义，15秒自动刷新

### 2.3 视频墙（VideoWall）

- **3×3 九宫格全屏视频墙**：按群组分类展示（港口堆场 / 道路监控 / 水体监控 / 重点企业 / 无人机视频）
- **"所有视频"模式**：合并所有群组统一展示
- **滚轮翻页**：超过9路视频时鼠标滚轮翻页浏览
- **智能缩略图**：**首次拉流成功后自动截图（255×125）**，作为视频流封面
- **多协议自适应播放**：HLS → http-flv → WebRTC 逐级降级，ZLMediaKit 核心转码，FFmpeg 兜底

### 2.4 视频轮播（VideoCarousel）

- **5个群组轮播**：无人机 / 港口堆场 / 道路监控 / 水体监控 / 重点企业
- **缩略图展示**：有截图时用截图铺底
- **LIVE/OFF 状态角标**：实时在线/离线状态
- **3×2 网格布局**：滚轮翻页，无自动轮播干扰

### 2.5 右侧统计面板（StatsPanel）

- **近7天告警趋势**：SVG 折线图，直观展示告警波动
- **告警类型占比**：Recharts 饼图，对接管理端"告警接入"+"气体采集预警"真实数据
- **智治推送排行 TOP5**：基于处置预案推送次数实时排行
- **污染事件排行**：重点企业污染事件频次排行
- **污染物浓度排行**：各污染物浓度对比

### 2.6 MQTT 实时告警

- **前端直连 MQTT Broker**：零延迟接收告警消息
- **前后端双向同步**：前端收到告警后自动推送到后端，触发智治推送引擎
- **实时地图标注**：告警点实时显示在地图上
- **告警弹窗**：新告警自动弹窗提示

### 4.2 智治推送引擎（⭐ 核心创新）

```
MQTT告警 → 事件入库(smart_push_events) 
        → checkRulesAndPush() 规则匹配
        → executePush() HTTP推送城运中心
        → 记录推送历史(smart_push_history)
```

- **事件驱动**：告警事件实时入库，自动触发规则匹配
- **规则引擎**：支持事件类型、位置、时间窗口、触发阈值等多维匹配
- **预案联动**：规则匹配后自动调用对应处置预案
- **全链路追溯**：事件 → 规则 → 推送 → 结果，完整记录

### 4.3 定时采集调度器

- **周期调度**：每15秒检查数据源，按各自采集周期独立触发
- **双类型采集**：`cq_api`（API接口）和 `html_crawl`（网页爬取）
- **断路器保护**：连续失败自动熔断，保护上游服务
- **超标预警**：采集数据超标自动生成预警记录

### 4.4 视频流转码引擎

- **编码自适应**：H.264 直播流直接输出；H.265 源自动转码为 H.264
- **FFmpeg Worker**：独立的转码工作进程，不阻塞主服务
- **多协议输出**：统一通过 ZLMediaKit 输出 HLS/FLV/WebRTC
- **Nginx 反向代理**：统一的 `/jsc/` 和 `/jsc_h264/` 路径分发

### 4.5 短信预警系统

- **云MAS 对接**：对接中国移动云MAS平台
- **自动/手动双模式**：告警自动触发 + 管理端手动发送
- **30分钟去重**：同一告警不重复发送
- **黑名单过滤**：自动过滤不接收号码
- **送达回执**：接收并记录送达状态

### 4.6 系统运维

- **一键备份**：`jsc-rollback create` 全量备份（后端+前端+数据库+nginx配置）
- **一键回滚**：`jsc-rollback restore <快照>` 7步原子化回滚
- **健康检查**：`/api/health` 实时系统状态
- **文件完整性**：`/api/health/files` 核心文件校验
- **原子写保护**：JSON文件写入前滚动备份3份，序列化自校验



## 五、技术创新点（10 大亮点）

### 🌟 创新一：智治推送引擎 —— 从"发现告警"到"处置闭环"

传统系统只能"看到"告警。本系统实现了完整的 **事件→规则→预案→推送** 闭环链路。MQTT 告警事件入库后，推送引擎自动匹配规则，通过 HTTP 推送到城运中心，实现跨部门协同处置。这是从"态势感知"到"智能决策"的质变。

### 🌟 创新二：MQTT 实时告警 —— 双向同步架构

前端直连 MQTT Broker 实现零延迟告警展示。同时，前端将告警数据同步到后端入库，触发智治推送。这种"前端展示 + 后端处置"的双向架构，兼顾了实时性和业务完备性。

### 🌟 创新三：ZLM 多协议视频流管理 —— 全链路自适应播放

系统支持 RTSP 摄像头源 → ZLMediaKit 转码 → HLS / FLV / WebRTC 多协议输出。H.264 源直出，H.265 源自动转码。前端播放器按 HLS → FLV → WebRTC 顺序逐级降级，兼容所有主流浏览器。

### 🌟 创新四：Canvas 视频流自动截图 —— 智能缩略图生成

VideoWall 首次拉流成功后自动截图，作为视频流封面图展示在管理端和驾驶舱轮播中。无需手动上传缩略图，系统自动维护。255×125 精准裁剪，JPEG 压缩，对存储和带宽友好。

### 🌟 创新五：定时采集调度器 —— 多源异构数据汇聚

支持 API 接口和网页爬取两种采集模式，按数据源独立配置采集周期。内置断路器保护机制，连续失败自动熔断。采集数据超标自动生成预警。

### 🌟 创新六：云MAS 短信预警系统 —— 智能去重 + 黑名单

对接中国移动云MAS平台，实现告警自动短信推送。30分钟去重避免骚扰，黑名单自动过滤。支持变量模板渲染，送达回执接收。

### 🌟 创新七：RBAC 三级角色权限 —— 精细化管理

admin（系统管理员）/ operator（操作员）/ viewer（观察者）三级权限，覆盖全功能页面。不同角色看到不同菜单，操作权限受控。

### 🌟 创新八：ONVIF 设备发现 + GB28181 国标对接 —— 摄像头生态全覆盖

支持 ONVIF 协议局域网摄像头自动发现，也支持 GB28181 国标信令对接。无论是新装设备还是存量国标设备，都能快速接入。

### 🌟 创新九：一键备份回滚体系 —— 运维安全网

`jsc-rollback` 命令支持 create/list/verify/restore 四大操作。回滚时7步原子化执行：验证快照→急救备份→停止服务→恢复数据库→恢复后端→恢复前端→恢复nginx。覆盖数据库、代码、配置全维度。

### 🌟 创新十：原子写数据保护 —— 数据完整性保障

JSON 配置文件写入前滚动备份3份，写入后序列化自校验。使用 `rename` 原子操作确保文件写入安全，防止进程崩溃导致文件损坏。
