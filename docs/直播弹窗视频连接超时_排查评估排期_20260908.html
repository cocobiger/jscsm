一、排查结论（根因）

根因：弹窗播放地址错误地指向了公网未开放的 6080 端口，导致浏览器拉流超时。

1.1 四层证据链

层实测结论
OSD / 司空 ZLM三峡学院无人机 0S4G 真飞（droneInDock=0），司空推 live/1581F8HGX258600A0S4G真飞 + 流正常
我方 ZLM mirrorjsc/sikong_1581F8HGX258600A0S4G alive=189s，mirror 成功镜像成功
stream-status 接口返回 hls = "http://111.10.220.226:6080/jsc/sikong_.../hls.m3u8"（绝对地址 + 6080 端口）地址错误
外网 6080 可达性iptables NAT 无 6080 DNAT 映射；外网访问 111.10.220.226:6080 超时（000）端口不通

1.2 根因链

stream-status 返回 hls = "http://111.10.220.226:6080/jsc/sikong_.../hls.m3u8" ↓ （绝对地址 + 6080 端口） 前端 SinglePlayer 直接 loadSource 该地址 ↓ 浏览器访问 111.10.220.226:6080 ↓ 6080 端口公网未开放（无 DNAT）→ 连接超时 ↓ 「视频连接超时」

正确做法：hls 地址应返回走 nginx 反代的相对路径 /jsc/sikong_.../hls.m3u8（浏览器走当前域名 :80/:81，nginx 反代到 127.0.0.1:6080）。nginx 的 /jsc/sikong_ 反代在 :80（uav-sites）和 :81（skymonitor.conf）都已配置，相对路径完全可行。

1.3 连带发现的第二个 bug

问题详情
