2 · 你这套模块的「共同范式」（值得固化成规范）

从 5 个新模块的文件头看，你已经形成了一套很稳定的做法，建议直接写成新模块模板： 
① 纯新增、最小侵入：自建表 + 自管配置 + 自注册路由；index.js 只加 1 行 require
   🔴 require 必须放在 adminOnly 定义之后 —— const TDZ，提前引用会 ReferenceError 崩进程
② 不动研判闸门：judgeWarning / isGateExemptWarning / queryWarningsAggregated 一律不碰
   （改它们会同时改变前台实时告警量与 SSOT 口径）
③ 真源在 DB（kv_config / 自建表），env 只作首次初始化 ⇒ 后台填完即生效、无需重启
④ 时间一律上海时 UTC+8（getUTC* + 8h），禁用 toLocaleString / 本地时区
⑤ 内网端点：PUBLIC_PATHS 放行 session 鉴权，路由内自校验 X-Admin-Token（复用 ALARM_ADMIN_TOKEN）
⑥ 高危动作走 dry-run 预览 → 确认 → 批量应用 + 快照（可一键回滚）
⑦ 出站禁止兜底：映射未命中 = 不上报（错码值进政府系统且事件单难撤回）
