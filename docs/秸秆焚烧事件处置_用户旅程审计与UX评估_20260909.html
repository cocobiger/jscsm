一、结论摘要

业务链路 80% 已实现，闭环基本打通；核心痛点集中在地图定位的「准确性」上。

① 算法识别 → OSD 坐标 → 镇街反查 → 责任单位 → 事件卡片 → 人工复核，六大环节全部已有实现；
② P0 痛点：腾讯地图导航坐标偏移——告警坐标是 WGS-84（OSD GPS），但腾讯地图链接未转 GCJ-02，手机端导航偏移约 300~500 米；
③ P1 痛点：坐标精度依赖三层降级（engine → OSD 精确定位 → 兜底万州中心）+ 手机端「自动导航」是网页链接非 App 深链；
④ 开发排期约 0.8 天，P0 一行坐标转换即可修复。
