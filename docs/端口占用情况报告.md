## 五、关键发现

### ⚠️ 问题

1. **ZLMediaKit 已停止** — 容器 `zlmediakit-server` 状态为 `Created`（未运行），RTSP 流媒体转发功能不可用。需执行 `docker start zlmediakit-server`。

2. **两个 MQTT Broker 并存** — ThingsBoard (端口 1883/8883) 和 EMQX (端口 8083/8084) 同时运行，需确认 JSC 系统对接的是哪一个。

3. **两个流媒体服务器** — SRS 和 ZLMediaKit 并存，SRS 占用 1935/8080 等端口，但 JSC 系统配置对接的是 ZLMediaKit。

4. **端口 7070 仍被 ThingsBoard 占用** — 之前因此将后端迁移到 7170，该端口仍是 ThingsBoard 的 Web 管理界面。
