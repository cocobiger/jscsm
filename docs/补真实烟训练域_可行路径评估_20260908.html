补真实烟训练域 · 可行路径详细评估
—— 解决「模型对真实烟盲（检出率 ~6.7%）」的训练数据路径
编制时间：2026-09-08数据来源：stage2 实测 + v5 训练集盘点性质：技术路径评估

一、结论摘要

根因确认：模型对真实烟盲，是"训练数据里没有足够的 DJI 真实烟（尤其远景淡烟）样本"，不是模型精度/阈值/分辨率问题。

最快可控路径：主动制造真实烟（烧秸秆/垃圾 + 无人机在典型巡逻高度拍 + 人工标注），1~2 天采集可出 300~500 张真实烟帧，配合 v5_syn 预训 + 真实烟微调，有望把真实烟检出率从 ~6.7% 提升到 60%+。

总周期约 4~6 天（采集 1~2 天 + 标注 1 天 + 训练 1 天 + 验证 1 天）。

2.2 训练数据构成（问题根源）

数据集规模域特征
v5_syn 合成远烟800 张合成白块/雾，形态不真实，但模型 100% 检出（训练时的主力）

DJI 远景淡烟真实样本≈0模型完全没见过的域——这是检出率 ~6.7% 的根因

核心结论：模型用 v5_syn（合成烟）训练，学会了"识别合成白块的样子"，但没见过"DJI 远景淡烟的真实样子"。微信真烟图是近景浓烟，域不同，也救不了。这是典型的域偏移（domain gap）。

之前所有努力（v52~55 续训 / E1 降阈值 / G1 1080p / 段2续训）都失败，因为它们都在"调模型"，而问题在"缺数据"——模型精度、阈值、分辨率都救不了"没见过的域"。

三、真实烟样本获取的 3 条路径

路径 ① 主动制造真实烟（推荐，最快可控）

项内容
做法在空旷安全场地烧秸秆/干草/垃圾，无人机在典型巡逻高度（100~300m）盘旋拍摄，覆盖不同角度/距离/光照，人工标注烟框
优势可控、快速、烟形态真实——烟是真实燃烧的烟（颜色/动态/扩散形态真实），且能精确控制拍摄距离/角度（模拟真实巡逻的远景淡烟场景）
样本量一次燃烧 + 多机位拍摄可出 50~150 帧（不同距离/角度/光照），3~5 次不同场景（白天/黄昏/不同背景）可凑 300~500 帧
成本无人机飞行（已有）+ 燃烧材料（秸秆/干草，成本低）+ 人工拍摄 1~2 天
周期1~2 天（采集）
风险需选空旷安全场地（防火）；燃烧需少量可控（避免大烟雾污染环境/被投诉）；建议选城郊/厂区空地

路径 ② 历史数据挖掘（辅助，补充）

项内容
做法从 dock_media 取证库（8 段 V 档视频，2.5G）+ 历史告警记录里，抽帧人工筛出"真烟帧"标注
现状取证库 8 段视频，但大多是误报/无清晰烟（今天实测 v4/v1 烟太淡，模型 0 框）；历史 smoke 告警 153 条，但大多是 fire 误判/干扰
样本量估计能筛出 20~50 张真烟帧（有限）
成本抽帧 + 人工筛选 ~0.5 天
评价辅助补充——样本少、质量参差，不能作为主力，但可作为真实域的补充多样性

路径 ③ 真实巡逻遇到（被动，慢）

项内容
做法日常无人机巡逻时，遇到真实秸秆焚烧/居民焚烧，手动截图/标记采集
评价被动、不可控、慢——真实焚烧可遇不可求（随机、看运气、看季节），无法保证样本量和周期
定位作为长期补充机制（巡逻采集常态化），不适合作为"快速补足"的主力路径

四、标注方案（人工整框，工作量）

项内容
方式人工整框（AI 预标对 DJI 白天烟失效，无法自动预标）
工具可复用现有复检/标注流程（或 CVAT/LabelImg 等开源工具，导出 YOLO 格式 txt）
标注要点① 烟柱整框（含烟雾扩散区）② 区分"真烟"vs"雾/云/反光"（负样本）③ 覆盖远景淡烟/近景浓烟不同形态
工作量300~500 帧 × ~30s/张 ≈ 3~5 小时人工（约 0.5~1 天）
负样本同步采集"无烟背景"（房屋/树木/雾/反光）作为负样本，neg:pos 保持 1:2~1:3（沿用 v5 策略）

五、训练策略（v5_syn 预训 + 真实烟微调）

项内容
框架沿用现有两阶段训练（stage1 v5_syn 预训 → stage2 真实烟微调），已有成熟流程
数据配比stage2 微调集 = 新增真实烟 300~500 帧 + v5_syn 部分（防遗忘）+ 负样本，真实烟占比提至 40~60%
关键改动把"DJI 远景淡烟真实样本"作为 stage2 主力，让模型学会真实烟特征
超参沿用 v5 策略：imgsz 1280、无 mosaic、copy_paste 0.3、neg:pos 1:2~1:3
训练时长stage2 微调 ~1 天（GPU 3090，几百张样本，60 epochs）

六、样本需求量估算 + 验收标准

项内容
最低有效量~200~300 张真实烟帧（标注）——让模型初步学会真实烟特征，检出率提升至 40%+
理想量~500~1000 张——检出率提升至 60~70%+，覆盖不同距离/角度/光照/背景
验收标准① 用今天实测的"DJI 白天视频 v4/v1"复测：从 0 框 → 检出（conf>0.3）② 微信真烟图检出率：从 ~6.7% → 60%+ ③ 真飞验证：实际巡逻遇到真烟能检出

七、推荐路径 + 排期

阶段任务工作量产出
阶段1 采集主动制造真实烟：选空旷场地烧秸秆/干草，无人机 100~300m 多机位拍摄（3~5 场景）1~2 天300~500 帧真实烟视频/帧
阶段2 挖掘历史视频挖掘：dock_media 8 段视频抽帧筛真烟0.5 天20~50 帧补充
阶段3 标注人工整框（含负样本）1 天YOLO 格式标注集
阶段4 训练v5_syn 预训 + 真实烟微调（stage2）1 天新模型（best.onnx）
阶段5 验证离线复测（v4/v1/微信图）+ 真飞验证1 天检出率验证报告

总周期约 4~6 天（其中主动采集是瓶颈，取决于天气/场地安排）。

八、结论

① 根因确认：模型对真实烟盲 = 训练数据缺"DJI 远景淡烟真实样本"（域偏移），不是模型/阈值/分辨率问题；
② 最快可控路径 = 主动制造真实烟：烧秸秆/干草 + 无人机巡逻高度拍 + 人工标注，1~2 天出 300~500 帧；
③ 训练策略 = v5_syn 预训 + 真实烟微调（沿用现有两阶段框架），真实烟占比提至 40~60%；
④ 预期效果：真实烟检出率从 ~6.7% → 60%+，总周期约 4~6 天；
⑤ 长期机制：巡逻采集常态化（遇到真实焚烧即截图回流），持续补充真实域。

本报告基于 2026-09-08 stage2 实测（微信图 1/15 检出、DJI 视频 0 框、合成烟 100%）+ v5 训练集盘点（v5_syn 800 合成 / v5_wechat 18 真实近景 / stage2 训练 196 图）。核心结论：补"DJI 远景淡烟"真实样本是唯一根治路径，主动制造真实烟最快可控。
