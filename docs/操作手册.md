## 一、登录与退出

### 1.1 登录系统

1. 打开浏览器，访问系统地址：
   ```
   http://111.10.220.226:81
   ```
2. 输入用户名、密码，点击「登录」。
3. 首次登录默认管理员账号为：
   - 用户名：`admin`
   - 密码：`admin123`
4. 首次登录后，系统会强制要求修改密码。

### 1.2 角色说明

| 角色 | 权限范围 | 可执行操作 |
|------|----------|------------|
| 管理员 | 全部功能 | 系统配置、用户管理、视频流/数据源/告警接入/图标等配置 |
| 值守员 | 日常值守 | 处理预警、手动触发采集、发送短信预警 |
| 访客 | 只读 | 查看驾驶舱和部分管理页面，不能进行任何写操作 |

### 1.3 修改密码

1. 点击管理后台右上角「改密」按钮。
2. 输入原密码、新密码、确认新密码。
3. 点击「确认」。

### 1.4 退出登录

- 点击管理后台右上角「登出」按钮，或直接关闭浏览器。

## 三、电子地图操作

### 3.1 地图说明

- 地图默认中心点：**经度 108.4076，纬度 30.8077**（万州区）。
- 默认缩放等级：**12**。
- 支持高德地图 **2D 模式**，暗色主题。

### 3.2 点位类型

| 图标颜色 | 类型 | 说明 |
|----------|------|------|
| 蓝色 | 空气监测 | 气环境监测站点 |
| 青色 | 水体监测 | 水环境监测站点、排污口 |
| 紫色 | 摄像头 | 视频监控点位 |
| 红色闪烁 | 告警 | 实时告警事件定位 |
| 黄色 | 无人机 | 无人机机场 / 气体快检设备 |
| 绿色 | 监测断面 | 流域水质监测断面 |

> **提示**：图标样式可在管理后台「地图图标配置」页面自定义。

### 3.3 鼠标交互

| 操作 | 效果 |
|------|------|
| 鼠标悬停点位 | 弹出信息窗，显示点位名称和详情 |
| 鼠标移开点位 | 信息窗自动关闭 |
| 双击摄像头/视频点位 | 弹出视频播放弹窗，实时播放该点位视频流 |
| 拖拽地图 | 平移地图视角 |
| 滚轮缩放 | 放大地图或缩小地图 |
| 点击地图空白处 | 关闭已打开的信息窗 |

> **注意**：地图双击缩放已禁用，避免与「双击播放视频」冲突。

### 3.4 图例说明

- 图例位于电子地图**左上方**，在「全域态势」Tab 下方。
- 点击图例右上角的「？」按钮，可展开鼠标与点位交互说明面板。

### 3.5 告警联动

- 左侧「实时告警」面板中的告警条被点击后，地图会自动定位到对应告警点位。
- 新告警点位会有红色脉冲呼吸动画。

## 四、视频监控操作

### 4.1 视频流分组

系统预置 5 个视频分组：

| 分组名称 | 颜色 | 用途 |
|----------|------|------|
| 无人机视频 | 紫色 | 无人机航拍画面 |
| 港口堆场 | 绿色 | 港口扬尘监控 |
| 道路监控 | 黄色 | 道路扬尘监控 |
| 水体监控 | 青色 | 水质相关监控 |
| 重点企业 | 橙色 | 企业排污监控 |

### 4.2 视频群组轮巡（3×2）

1. 在驾驶舱点击「视频轮巡」入口，打开视频群组轮巡面板。
2. 面板显示 **3 列 × 2 行 = 6 路**视频缩略图。
3. 顶部按钮可切换不同视频分组。
4. **鼠标滚轮**向下滚动：切换到下一页；向上滚动：切换到上一页。
5. 点击任意缩略图卡片，弹出视频播放弹窗。
6. 点击「▦ 视频墙」按钮，可打开全屏视频墙。

### 4.3 视频墙（3×3）

1. 视频墙为全屏九宫格，最多同时展示 **9 路**视频。
2. 顶部按钮可按分组过滤，或选择「所有视频」查看全部。
3. **鼠标滚轮**向下滚动：下一页；向上滚动：上一页。
4. 每页视频会自动播放，离线视频显示「离线」提示。
5. 点击背景区域或右上角「×」关闭视频墙。

### 4.4 视频播放弹窗

- 双击地图摄像头点位，或点击视频轮巡中的缩略图，会打开视频播放弹窗。
- 弹窗自动识别视频协议（HLS / FLV / WebRTC / RTSP / ONVIF / GB28181）。
- H.265 视频会自动走转码通道，转换为 H.264 后播放。
- 点击弹窗外区域或关闭按钮，关闭视频。

### 4.5 自动截图缩略图

- 视频墙中的视频成功播放 3 秒后，系统会自动截图一张，缩放到 255×125，作为该视频流的显示图片。
- 截图会同步保存到管理后台「视频流管理」页面中。

## 八、视频流管理

### 8.1 进入页面

依次点击：管理后台 → 视频流管理。

### 8.2 新增视频流

1. 点击「新增」按钮，打开新增弹窗。
2. 填写基本信息：
   - 名称：视频流名称
   - 位置：安装位置
   - 经纬度：用于地图定位
   - 分组：选择所属分组（无人机视频 / 港口堆场 / 道路监控 / 水体监控 / 重点企业）
   - URL：视频流地址
   - 协议：rtsp / hls / webrtc / onvif / gb28181
3. 选择协议后，部分协议会显示额外配置：
   - **RTSP**：直接填写 RTSP 地址，如 `rtsp://admin:password@192.168.1.100:554/live/main`
   - **HLS**：填写 HLS 地址或相对路径，如 `/jsc/xxx/hls.m3u8`
   - **ONVIF**：填写 ONVIF 服务地址
   - **GB28181**：填写 SIP 服务器、设备编码、通道编码、认证信息等
4. 点击「保存」。

### 8.3 编辑/删除视频流

- 在视频流列表中，点击某条记录右侧的「编辑」按钮可修改。
- 点击「删除」按钮可删除，删除前需确认。

### 8.4 启动/停止播放

- 视频流列表中会显示每路流的在线状态。
- 点击「播放」按钮可临时测试播放。
- 管理后台会自动维护视频流的推流状态。

### 8.5 视频流显示图片

- 视频流卡片支持上传显示图片，用于视频轮巡缩略图展示。
- 也可通过驾驶舱「视频墙」播放后自动生成截图作为显示图片。

## 九、智治推送

### 9.1 功能说明

智治推送用于对接城运中心，当发生指定告警事件并满足触发条件时，自动将告警信息推送到城运中心处置预案接口。

### 9.2 进入页面

依次点击：管理后台 → 智治推送。

页面包含三个 Tab：
- **处置预案**
- **推送规则**
- **推送历史**

### 9.3 配置处置预案

1. 切换到「处置预案」Tab。
2. 点击「新增预案」。
3. 填写：
   - 预案名称：如「巴渝治气」
   - 事件类型：气体污染 / 水体污染 / 秸秆燃烧 / 道路扬尘 / 堆头未覆盖
   - HTTP 方法：POST / GET / PUT
   - 接口地址：城运中心接收告警的 URL
   - 请求头（JSON 格式）
   - 报文模板（JSON 格式，支持变量替换）
   - 描述
   - 启用状态
4. 点击「保存」。

**报文模板可用变量**：
```
{event_type}    事件类型
{location}      发生地点
{lat}          纬度
{lon}          经度
{level}        告警级别
{value}        监测值
{standard}     标准限值
{time}         触发时间
{description}  描述
{trigger_count} 触发次数
{event_ids}    事件ID列表
```

### 9.4 配置推送规则

1. 切换到「推送规则」Tab。
2. 点击「新增规则」。
3. 填写：
   - 规则名称
   - 事件类型
   - 关联预案（下拉选择已启用的处置预案）
   - 点位匹配（模糊匹配，留空表示所有点位）
   - 时间窗口（小时，默认 48）
   - 触发次数阈值（默认 5）
   - 启用状态
4. 点击「保存」。

**规则触发逻辑**：当指定事件类型在指定点位的时间窗口内累计触发达到阈值时，自动按关联预案向城运中心推送。

### 9.5 查看推送历史

1. 切换到「推送历史」Tab。
2. 顶部显示统计：推送总数、成功数、失败数、告警事件总数。
3. 可按事件类型筛选历史记录。
4. 点击某条记录右侧「详情」按钮，可查看：
   - 触发时间
   - 事件类型和点位
   - 触发次数
   - 推送接口地址
   - HTTP 状态码
   - 失败原因（如有）
   - 请求报文和响应内容

## 十、告警接入配置

### 10.1 进入页面

依次点击：管理后台 → 告警接入。

### 10.2 配置告警 JSON 映射

1. 在告警接入页面，配置外部系统推送告警时的 JSON 字段映射关系。
2. 支持的字段包括：
   - 事件类型字段
   - 地点字段
   - 经纬度字段
   - 告警级别字段
   - 监测值字段
   - 标准限值字段
   - 时间字段
3. 配置完成后，外部系统通过 MQTT 或 HTTP 推送的告警即可被正确解析入库。

### 10.3 测试告警推送

1. 在告警接入页面，填写测试 JSON 报文。
2. 点击「测试推送」按钮。
3. 系统会模拟一次告警入库，并返回解析结果。

## 十一、气体采集预警

### 11.1 进入页面

依次点击：管理后台 → 气体采集预警。

### 11.2 数据源管理

1. 查看已配置的气体监测数据源列表。
2. 点击「新增数据源」配置新的监测站点。
3. 数据源配置包括：站点名称、接口地址、采集频率、污染物指标、预警阈值等。
4. 点击「测试连接」验证数据源是否可用。
5. 点击「手动采集」可立即触发一次数据采集（值守员及以上权限）。

### 11.3 预警记录

- 页面会展示所有采集到的气体预警记录。
- 可按时间、站点、污染物类型筛选。
- 值守员可点击「处理」按钮，填写处理意见后标记为已处理。

### 11.4 预警规则

- 配置各污染物的预警阈值。
- 支持多级阈值：注意 / 轻度 / 中度 / 重度。

4. 点击「删除」可移除企业。

### 13.3 污染事件管理

1. 在企业详情或污染事件列表中查看事件记录。
2. 事件包括：发生时间、类型、点位、超标值、处理状态等。
3. 值守员可点击「处理」按钮，填写处理结果。

## 十五、常见问题

### Q1：视频播放黑屏/无法加载？

- 检查视频流 URL 是否正确。
- 检查摄像头是否在线、网络是否可达。
- 确认视频编码为 H.264；如为 H.265，系统会自动转码，需等待数秒。
- 检查浏览器是否支持当前协议（Chrome/Edge/Firefox 推荐）。

### Q2：地图点位不显示？

- 检查「地图图标配置」中是否已配置该点位类型的图标。
- 检查地图点位数据是否已正确录入。
- 检查网络连接和高德地图 Key 是否有效。

### Q3：告警没有推送？

- 检查 MQTT 连接状态是否正常。
- 检查「告警接入」中的 JSON 映射是否正确。
- 检查「智治推送」中的处置预案和规则是否已启用。
- 查看「推送历史」中的失败原因。

### Q4：短信发送失败？

- 检查「短信预警推送」中的云MAS配置是否正确。
- 检查联系人手机号格式是否正确。
- 查看短信发送历史中的状态报告。

### Q5：视频墙翻页没有反应？

- 确认视频总数超过 9 路，否则无需翻页。
- 使用鼠标滚轮在视频墙区域内上下滚动。
- 也可点击底部的分页圆点切换。
