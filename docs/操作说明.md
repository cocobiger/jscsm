# 万州区生态环境局智能AI大数据驾驶舱系统 —— 操作说明

> 版本：v2.0 | 日期：2026-06-18



## 一、驾驶舱操作指南

### 1.1 登录系统

1. 浏览器打开系统地址（由管理员提供）
2. 输入用户名和密码，点击"登录"
3. 登录后即进入驾驶舱主界面（全域态势视图）

### 1.2 顶部导航栏

| 操作 | 说明 |
|------|------|
| 切换视图 | 点击"全域态势""气环境驾驶舱""水环境驾驶舱"Tab，切换不同视图 |
| 查看实时数据 | 导航栏右侧显示监测站数量、摄像头数量、今日告警数，自动刷新 |
| 无人机溯源 | 点击"无人机溯源"按钮，跳转到无人机溯源追踪平台 |

### 1.3 地图操作

#### 基本操作

| 操作 | 方式 |
|------|------|
| 平移地图 | 鼠标拖拽 |
| 缩放地图 | 鼠标滚轮 或 右下角 +/- 按钮 |
| 查看交互说明 | 点击地图右上角"?"按钮，弹出操作指南面板 |

#### 标注交互

| 操作 | 说明 |
|------|------|
| **悬停查看数据** | 鼠标移到监测站/气站标注上，自动弹出信息窗，显示最新 AQI / PM2.5 / PM10 / SO₂ / NO₂ / O₃ / CO 数据 |
| **双击播放视频** | 双击摄像头或无人机标注，自动拉流并弹出视频播放窗口 |
| **关闭信息窗** | 点击地图空白区域、拖拽或缩放地图即可关闭 |
| **查看图例** | 地图左上角图例面板展示所有标注类型 |

#### 视频播放弹窗操作

| 操作 | 说明 |
|------|------|
| 播放视频 | 双击摄像头标注后自动播放，弹窗展示720p视频画面 |
| 关闭视频 | 点击弹窗外任意位置 或 点击右上角关闭按钮 |
| 注意 | 关闭视频后，地图自动恢复到双击前的位置和缩放等级，不会偏移 |

### 1.4 视频墙

#### 打开视频墙

1. 在驾驶舱下方点击"视频墙"按钮
2. 系统以 3×3 九宫格布局展示视频流

#### 视频墙操作

| 操作 | 说明 |
|------|------|
| 切换群组 | 顶部群组标签选择：无人机视频 / 港口堆场 / 道路监控 / 水体监控 / 重点企业 / 所有视频 |
| 翻页浏览 | 当视频超过9路时，使用**鼠标滚轮**上下翻页 |
| 查看状态 | 每路视频左上角有角标：LIVE（在线）/ OFF（离线） |
| 关闭视频墙 | 点击右上角关闭按钮 |

> **提示**：视频墙拉流成功后会自动截图（255×125），作为该路视频流在管理端的缩略图。

### 1.5 视频轮播

#### 视频轮播操作

| 操作 | 说明 |
|------|------|
| 浏览视频 | 每个群组以 3×2 网格展示视频截图 |
| 翻页 | 使用**鼠标滚轮**在视频间翻页 |
| 播放视频 | 点击任意视频卡片的缩略图，打开全屏播放器 |
| 查看状态 | LIVE / OFF 角标显示实时在线状态 |

### 1.6 右侧统计面板

驾驶舱右侧为数据统计面板，包含以下板块：

| 板块 | 内容 | 刷新方式 |
|------|------|----------|
| 近7天告警趋势 | 折线图展示告警数量变化 | 自动刷新 |
| 告警类型占比 | 饼图展示各类告警占比 | 自动刷新 |
| 智治推送排行 TOP5 | 推送次数排行 | 10秒自动刷新 |
| 污染事件排行 | 企业污染事件频次排行 | 60秒自动刷新 |
| 污染物浓度排行 | 各污染物浓度对比 | 自动刷新 |

### 1.7 MQTT 实时告警

- 当有新的 MQTT 告警到达时，地图上自动标注告警点位
- 告警弹窗自动弹出，显示告警详情（类型、数值、位置、时间）
- 告警自动同步到后端，触发智治推送引擎



## 二、管理端操作指南

### 2.1 进入管理端

1. 在驾驶舱界面找到"管理"入口（由管理员配置）
2. 或直接访问管理端地址
3. 管理端采用左侧导航栏 + 右侧内容区布局

### 2.2 系统总览

**位置**：左侧导航 → 系统总览

| 可查看的信息 | 说明 |
|-------------|------|
| 连接状态 | MQTT Broker、ZLMediaKit、数据库的连接状态（绿色=正常、红色=异常） |
| 核心指标 | 采集记录数、告警数、推送数、设备在线率 |

### 2.3 视频流管理

**位置**：左侧导航 → 视频流管理

#### 添加视频流

1. 点击"添加视频流"按钮
2. 填写流信息：
   - **名称**：摄像头名称（如"港口1号摄像头"）
   - **群组**：选择所属群组（港口堆场 / 道路监控 / 水体监控 / 重点企业 / 无人机视频）
   - **协议**：选择 RTSP 或 HLS
   - **URL**：填写视频流地址（如 `rtsp://192.168.1.100:554/stream1`）
3. 点击"保存"

#### 推流控制

| 操作 | 说明 |
|------|------|
| 开始推流 | 点击"推流"按钮，系统将通过 ZLMediaKit 启动转码推流 |
| 停止推流 | 点击"停止推流"按钮，停止转码推流 |
| 健康检查 | 点击"健康检查"，批量检测所有流在线状态 |

#### 编辑/删除视频流

- 点击列表右侧的"编辑"按钮修改配置
- 点击"删除"按钮删除该视频流

### 2.4 流媒体服务器（仅 admin）

**位置**：左侧导航 → 流媒体服务器

- 查看 ZLMediaKit 节点配置
- 查询各视频流的播放地址
- 测试 ZLMediaKit 连通性

> **注意**：此页面仅 admin 角色可见，普通操作员和观察者无权限访问。

### 2.5 MQTT 配置（仅 admin）

**位置**：左侧导航 → MQTT配置

- 配置 MQTT Broker 地址、端口、用户名/密码
- 管理订阅的 Topic
- 测试连接

### 2.6 告警接入（仅 admin）

**位置**：左侧导航 → 告警接入

- 配置 JSON 格式映射规则（将 MQTT 消息字段映射为系统告警字段）
- 发送测试告警验证映射规则

### 2.7 智治推送（仅 admin）

**位置**：左侧导航 → 智治推送

这是系统的核心功能页面，包含三个 Tab：

#### 处置预案 Tab

| 操作 | 说明 |
|------|------|
| 新建预案 | 点击"新建预案"，填写预案名称、推送目标URL、推送内容模板 |
| 编辑预案 | 点击预案列表中的"编辑"按钮 |
| 删除预案 | 点击"删除"按钮 |

#### 推送规则 Tab

| 操作 | 说明 |
|------|------|
| 新建规则 | 点击"新建规则"，配置：事件类型（气体污染/水体污染/秸秆燃烧/道路扬尘/堆头未覆盖）、关联预案、触发条件（时间窗口、阈值） |
| 编辑规则 | 点击规则列表中的"编辑"按钮 |
| 删除规则 | 点击"删除"按钮 |

#### 推送历史 Tab

- 查看所有推送记录：推送时间、预案名称、推送目标、推送结果
- 支持按时间范围筛选

> **工作流程**：MQTT 告警到达 → 事件入库(smart_push_events) → 匹配推送规则 → 调用处置预案 → HTTP 推送城运中心 → 记录推送历史。

### 2.8 市局监测站数据

**位置**：左侧导航 → 市局监测站数据

- 查看所有监测站信息
- 查看各监测站整点采集数据
- 将数据推送至上级系统

### 2.9 气体采集预警

**位置**：左侧导航 → 气体采集预警

#### 数据源管理

| 操作 | 说明 |
|------|------|
| 添加数据源 | 选择类型：`cq_api`（API接口采集）或 `html_crawl`（网页爬取采集），填写URL和采集周期 |
| 手动采集 | 点击"手动采集"按钮立即触发一次数据采集 |
| 诊断 | 点击"诊断"按钮检测数据源连接状态 |
| 清除断路器 | 如果数据源因连续失败被断路保护，点击"清除断路器"恢复 |

#### 预警记录

- 查看气体超标预警记录列表
- 点击"批量处理"将全部预警标记为已处理
- 单个预警可点击"处理"逐条标记

### 2.10 短信预警推送（operator+）

**位置**：左侧导航 → 短信预警推送

#### 短信联系人管理

| 操作 | 说明 |
|------|------|
| 添加联系人 | 填写姓名、手机号、分组 |
| 编辑/删除 | 点击列表中的"编辑"或"删除"按钮 |

#### 短信模板管理

| 操作 | 说明 |
|------|------|
| 新建模板 | 填写模板名称和内容（支持变量如`${station}`、`${value}`） |
| 预览 | 点击"预览"查看变量渲染后的效果 |
| 编辑/删除 | 点击列表中的"编辑"或"删除"按钮 |

#### 短信发送

| 发送方式 | 说明 |
|---------|------|
| 手动发送 | 选择联系人，填写内容，点击发送 |
| 模板发送 | 选择模板，选择联系人，自动渲染后发送 |

#### 短信黑名单

- 添加不接收短信的号码
- 系统发送短信前自动过滤黑名单号码

#### 短信配置（仅 admin）

- 配置云MAS API 地址、Key、Secret
- 点击"测试发送"验证配置

### 2.11 数据统计报表

**位置**：左侧导航 → 数据统计报表

- 采集趋势图表
- 超标统计
- 告警统计（类型、频次）
- 设备状态（在线率）

### 2.12 重点企业管理（operator+）

**位置**：左侧导航 → 重点企业管理

| 操作 | 说明 |
|------|------|
| 添加企业 | 填写企业名称、位置、排放类型等信息 |
| 编辑/删除 | 点击列表中的"编辑"或"删除"按钮 |
| 污染事件 | 查看该企业的污染事件记录 |

### 2.13 地图图标配置（仅 admin）

**位置**：左侧导航 → 地图图标配置

- 自定义各类型标注的图标样式
- 修改后地图上立即生效

### 2.14 用户管理（仅 admin）

**位置**：左侧导航 → 用户管理

| 操作 | 说明 |
|------|------|
| 创建用户 | 填写用户名、密码、角色（admin/operator/viewer） |
| 编辑用户 | 修改角色或禁用/启用账号 |
| 删除用户 | 删除用户账号 |
| 重置密码 | 重置指定用户的密码 |
| 修改密码 | 修改当前登录用户的密码 |

## 四、常见问题

### Q1：摄像头画面无法加载？

1. 检查流媒体服务器连接状态（管理端 → 系统总览）
2. 检查 ZLMediaKit 容器是否运行（联系管理员）
3. 点击"推流"按钮重新推流
4. 尝试刷新浏览器页面

### Q2：地图标注不显示？

1. 确认浏览器网络连接正常
2. 等待15秒（标注数据自动刷新周期）
3. 刷新浏览器页面

### Q3：告警数据没有实时更新？

1. 检查 MQTT 连接状态（管理端 → 系统总览）
2. 确认 MQTT Broker 正常运行（联系管理员）
3. 刷新浏览器页面

### Q4：智治推送没有触发？

1. 进入管理端 → 智治推送，确认：
   - 处置预案已创建
   - 推送规则已配置（事件类型匹配、关联预案正确）
2. 确认推送目标 URL 可访问
3. 查看推送历史，确认是否有执行记录和错误信息

### Q5：数据采集无新数据？

1. 进入管理端 → 气体采集预警
2. 对数据源执行"诊断"操作
3. 检查断路器状态，如已触发则"清除断路器"
4. 点击"手动采集"测试数据源

### Q6：忘记密码？

联系系统管理员（admin 角色）重置密码。

### Q7：系统出错需要回滚？

由运维人员执行回滚命令：
```bash
# 查看可用备份
jsc-rollback list

# 回滚到指定快照
jsc-rollback restore <快照时间戳>
```

回滚覆盖范围：后端代码、前端页面、数据库、nginx配置，7步原子化操作，无需手动干预。
