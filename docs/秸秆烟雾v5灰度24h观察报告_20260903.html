④ 代码级根因（本次观察新发现）

🐛 main.py L249 NameError：非告警帧必崩，复检收集恒 0

if res[0] == 'alert':
    ...
    label = CLASSES[cls_id]        # ← L203 label 仅在此分支赋值
    ...
else:
    # 复检记录：单帧命中（未确认）+ 随机抽帧
    recorder.maybe_record(sid, frame, boxes, res, label, ...)   # ← L249 引用未定义 label
  • 非告警帧（模型未确认 = 常态，v5 全盲下即每一帧）走 else 分支 → NameError: local variable 'label' referenced before assignment → 每帧打印错误并 sleep 2s → 复检记录/低置信抽帧永远无法落库，且实际拖慢 worker 帧率。
  • 告警路径（if 分支）不受影响：若模型真能检出 ≥3 连续帧，仍会正常落库+上报 —— 所以「0 落库」依然是模型全盲的硬证据。
  • Bug 自 8/31 16:27 版 main.py 即存在（本次 v5 部署仅换了 detector.py + config）；RT-DETR 时代靠告警路径产出行，掩盖了此 Bug。
  • 影响面：straw_detections 复检收集链（P2 scene / P3 straw_neg_reviews 负样本）自该版本起即断供。
