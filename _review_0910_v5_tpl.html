📖 功能说明（逐项：用途 / 操作 / 为什么这样设计 / 误操作后果）

① 五类帧判定（有烟 / 无烟 / 干扰无烟 / 无效 / 不确定）

用途：决定每帧以什么身份进入数据集。操作：卡片下方按钮，或标框弹窗内 N / I / X / ? 快捷键。判定顺序：先看不清→无效X；有烟→红框（自动=有烟）；没烟但有易误检物→干扰无烟I+青框；干净背景→无烟N；拿不准→不确定?（不进训练）。
误操作后果：把「淡烟」误标成无烟 = 未标注正样本，模型学不到；把「灯光/火光」标成有烟 = 教模型「亮斑=烟」，白天大量误报。

② 红框（烟羽）与 青框（干扰区）

用途：区域级监督 —— 红框告诉模型「这是烟」，青框告诉模型「这里不是烟」。操作：弹窗顶部切换框类型（快捷键 1 / 2）；单击已画框可切换类型；双击删框。
「干扰无烟 I」不会跳帧：点它（或按 I）后页面停在本帧并自动切换到青框模式，信息栏会提示「请拖动画青框圈出干扰区」，画完按 Enter 确认才进入下一帧。这是 9/11 修复的旧缺陷 —— 之前会直接跳走，导致来不及画青框。
为什么：9/9 那批干扰区青框 = 0 个，模型只能靠整帧「无烟」学抑制，学不会抑制哪些区域，夜间亮区因此误报。
误操作后果：火点画红框 = 教模型「橙色亮斑=烟」→ 白天在篝火/路灯/橙红屋顶误报，是污染淡烟检测最快的方式。火点永远画青框。

③ 🌙 夜帧徽标 + 夜间青框提醒

用途：夜帧（亮度低或 19:00 后拍摄）容易把城镇灯光/反光当成烟。操作：夜帧标记「无烟」时，若一个青框都没画，会弹确认，要求你圈出易混淆亮区；可跳过但会被记录在导出报告里。
为什么：stage4 失败根因 —— 夜间负样本与真烟帧视觉几乎同景（同款城镇灯光），模型分不清「无烟」和「有烟但没标」。

④ 同景警示（🟣 同景风险标记）

用途：当你把某帧标成「无烟」，但它邻近帧（同架次 ±5 帧内）已标为真烟时，弹警示并把该帧打上 🟣 标记、归入 hardNegAmbiguous 分区。
为什么：这类「同景负样本」正是 stage4 打乱决策边界的元凶。它们默认不进训练负样本，是否入集交给训练脚本按批决定 —— 标注端不再悄悄掺入。
误操作后果：若确实是真烟而误标无烟，不仅丢正样本，还会同时制造一个「明明有烟却说没烟」的错误负样本，双重污染。

⑤ 历史 318 帧锁定只读（🔒）

用途：9/9 已入集（828 行、stage3 现网模型）的标注在本页只读：可查看、不可改。操作：切到「历史锁定(318)」查看；确需修改须点 🔒 解锁并填写原因，修改记录进「变更日志」。
为什么：导出是全量合并的，改一帧旧标注 = 已训练过的数据集悄悄变了（训练集漂移），且极难回溯。
误操作后果：改动旧标注后，本轮评测与 stage3 基线不再可比，模型好坏无法判断。

⑥ 导出体检单（硬门禁）

用途：点导出不会直接下载，先出体检单：新增正样本 / 新增负样本 / 正:负比 / 昼夜配比 / 同景风险清单 / 变更日志。操作：体检单里选「仅导出正样本包」或「仍全量导出（记录风险）」。
为什么：stage4 = +7 正样本却塞进 26 个高难负样本，正负增量失衡直接把召回从 95% 打到 75%。当「新增负样本 > 新增正样本 × 2」时全量导出被阻断。

⑦ 黑名单隔离（模拟器 / 机场直连流）

用途：SIM_SMOKE（107 帧模拟数据）与机场直连流（机库画面）默认不出现在本页；即便被强行载入，也带 ⛔ 禁标标记且导出时硬性剔除。
误操作后果：模拟数据入训练集 = 指标虚高、真飞全瞎。

⑧ 全黑 / 残帧（模糊）自动预检

用途：生成页面时逐帧算亮度与清晰度（拉普拉斯方差 lap）：全黑（亮度<8）或 lap < 80 的帧自动预标「无效帧 X」，卡片标 ⚠️残帧/模糊 并灰显。操作：一般直接跳过（筛选「待标注」时它们已不在列表里）；若你认为某帧其实可用，可以手动改回判定。
为什么：9/9 曾出现 9 帧全黑险些入集；9/11 白天批次又发现 47 帧「录制末尾残帧」（亮度正常但 lap 接近 0，是运动模糊/录制截断产物，集中在每段最后 1-3 帧）。这类帧边界糊，若在上面画红框当正样本，会给模型喂「边界不确定的正样本」，直接压低框级定位——而我们当前白天唯一的短板正是框召回（78.8%）。
误操作后果：把残帧当正样本画框 = 引入噪声；把它们当负样本 = 教模型「糊=没烟」，同样有害。所以统一判「无效」最安全。

⑨ 录制分段筛选（顶栏下拉）

用途：把抽帧按「录制分段」（同一架次的一段连续录制）分开标注，下拉里直接显示每段的 已标 / 总数 进度。操作：选一个段 → 只标该段 → 标完切下一段。
为什么建议按段标：同一段内画面连续、光照与地形一致、烟羽位置相邻，判定标准最容易保持一致，能显著降低「同景误标」；跨段跳着标则容易前后标准不一（这正是同景风险的来源）。

🔥 夜间有火怎么标（核心：火 ≠ 烟）

  1. 火点 / 火光本身 → 青框（干扰区）。绝对不要画红框
  2. 火点上方有可见烟柱 → 只框那一段烟（红框），不要把火点框进去
  3. 看不出烟 → 「干扰无烟 I」+ 火点青框
  4. 淡烟（稀释远烟）：低对比度、偏蓝灰、边缘发虚 —— 看得出是烟就照样标红框，这正是模型当前盲区
